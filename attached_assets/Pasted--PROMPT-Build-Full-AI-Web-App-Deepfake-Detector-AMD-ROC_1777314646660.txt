Build a complete, working web application for the following project:

---

## 🔹 Project Title

Deepfake Detector PRO – Multimodal AI Web App (AMD GPU + ROCm + Hugging Face)

---

## 🔹 Goal

Create a full-stack AI web application that allows users to upload an image or use a webcam to detect deepfakes, visualize manipulated regions, and generate explanations using multimodal AI. The application must run using AMD GPU acceleration (ROCm) and integrate Hugging Face models.

---

## 🔹 Mandatory Technologies (STRICT REQUIREMENT)

### ✅ AMD Developer Cloud

* The application must be designed to run on AMD Developer Cloud GPU instances
* Backend should support cloud deployment and GPU usage
* Mention where training and inference happen on cloud

### ✅ ROCm (AMD GPU Platform)

* Use PyTorch with ROCm backend
* Detect device using:
  device = "cuda" if torch.cuda.is_available() else "cpu"
* Ensure all model inference runs on GPU if available

### ✅ Hugging Face

* Use transformers library
* Load pretrained multimodal model (BLIP or LLaVA)
* Generate explanation from image
